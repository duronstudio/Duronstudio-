# Duron Studio Photography

A free, responsive static website designed for GitHub Pages.

## Publish
1. Create a GitHub account.
2. Create a public repository named `YOURUSERNAME.github.io`.
3. Upload `index.html`.
4. Go to Settings → Pages and select the main branch as the publishing source.
5. Open `https://YOURUSERNAME.github.io/`.

The current gallery uses visual placeholders. Replace them later with your own photographs.
